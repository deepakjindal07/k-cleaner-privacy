2. Scope & Nature of Services

K-Cleaner is designed to help Android users understand, organize, and manage device storage. The application provides the following core utilities:

  • Storage Overview & Categorization: Analyzes shared storage to display disk utilization across images, videos, audio, documents, archives, and APK packages.
  • Duplicate Media Finder: Identifies potential duplicate photos, videos, and files using cryptographic content hashing (SHA-256) and file metadata to help you identify redundant copies.
  • Junk File Scanning: Scans accessible shared directories for temporary files, empty folders, orphaned APK installer packages, and app log files.
  • Apps Manager: Displays installed applications, their installation date, and storage footprint, allowing you to launch Android's native system uninstallation flow.
  • Device & Battery Insights: Displays battery temperature, charging health, and RAM utilization heuristics using standard platform system APIs.
  • Quick Boost: Requests that Android terminate eligible background processes using Android's standard killBackgroundProcesses() API and clears only K-Cleaner's own internal temporary cache files.

3. Local Processing & User Responsibility for File Deletion

K-Cleaner is engineered with a strict local-first approach:

  • Local Analysis: All file scanning, duplicate hashing, and storage calculations take place directly on your Android device. K-Cleaner's application code does not transmit your personal files, photos, videos, or documents to external servers.
  • No Automated User-File Deletion: K-Cleaner does not delete personal files, photos, videos, or downloads automatically without user intervention. All deletion actions require your explicit selection and confirmation.
  • User Responsibility: You retain sole responsibility for reviewing file selections prior to confirming permanent deletion. You acknowledge that deleting files, duplicates, or installers is permanent and may not be reversible. We strongly recommend maintaining regular external backups of irreplaceable photos, videos, and critical documents.
  • App Cache Clearing: When using the Quick Boost feature, the app cleans only K-Cleaner's own temporary cache files. K-Cleaner does not delete the private caches of other installed applications.

4. Permissions & Android Platform Constraints

To perform storage maintenance and cleanup, K-Cleaner requests certain Android runtime permissions. Your use of the application is subject to the following platform constraints:

  • Optional Grants: You may grant or decline optional permissions (such as MANAGE_EXTERNAL_STORAGE on Android 11+, granular MediaStore permissions on Android 13+, Usage Access, or Notification permissions). If you decline a permission, features requiring that permission will be disabled or operate with reduced file visibility, while unaffected features remain functional.
  • Android Security Sandboxing: In accordance with Android platform security standards, K-Cleaner cannot and does not access, inspect, or clear the private internal sandboxes of other installed applications (such as /data/data/ or protected subdirectories under /sdcard/Android/data/).
  • Process Termination Limitations: When Process Explorer or Quick Boost requests process termination, it uses Android's standard ActivityManager.killBackgroundProcesses() API. The Android operating system retains ultimate control over process lifecycle and may restart background services as needed. K-Cleaner does not bypass Android platform protections or force-stop critical system processes.
