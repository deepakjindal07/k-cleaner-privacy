1. Developer Identity & Overview

This Privacy Policy explains how K-Cleaner ("the Application", "we", "our", or "us"), an Android application developed by Deepak Kumar, handles information when installed on your mobile device.

K-Cleaner is an Android storage maintenance and file management utility designed to help users inspect local storage utilization, discover potential junk files (such as obsolete temporary caches and redundant APK packages), find duplicate media, and organize files stored on their devices.

We are committed to data transparency, user control, and compliance with Google Play Developer Program Policies, the General Data Protection Regulation (GDPR), the UK Data Protection Act, the California Consumer Privacy Act (CCPA/CPRA), the Indian Digital Personal Data Protection Act (DPDP), and other applicable global privacy regulations.

2. On-Device File Scanning & Cleanup

K-Cleaner's primary features inspect shared storage on your device. The architectural principles governing file operations are:

  • 100% Local Scanning: When K-Cleaner scans your storage, calculates file sizes, groups files by extension or folder, or checks for duplicate photos and videos using content hashing, all computations occur strictly in-memory on your device.
  • No File Uploads: K-Cleaner does not transmit, upload, replicate, or synchronize your personal files, photos, videos, audio recordings, or documents to any remote server or cloud infrastructure.
  • Strict User Confirmation: K-Cleaner never deletes any file automatically or silently. Every deletion operation requires explicit selection and confirmation by the user.
  • Android Platform Boundaries: Under Android operating system security models, K-Cleaner cannot inspect, access, or clear private internal caches or data belonging to other applications (such as /data/data/ or protected /Android/data/ directories). Only K-Cleaner's own application cache can be cleared directly; for other applications, K-Cleaner acts as an informational assistant guiding you to Android's built-in system settings.

4. Usage Access, Process & Data Insights

When you grant the optional Usage Access permission (PACKAGE_USAGE_STATS), K-Cleaner accesses standard Android platform APIs to provide diagnostic information:

  • Application Last Used Times: Queries UsageStatsManager locally to help you identify apps you haven't opened in a long time.
  • Data Usage Monitoring: Queries NetworkStatsManager to display Wi-Fi and mobile data consumption per application over recent intervals. No network packets, browsing history, URLs, or message payloads are intercepted or recorded.
  • Process Explorer & Quick Boost: Inspects active process memory usage via ActivityManager.getRunningAppProcesses() and system memory metrics. Quick Boost terminates background processes using standard Android killBackgroundProcesses() and removes K-Cleaner's own temporary cache files. Reclaimed memory metrics reflect actual measured memory differentials.

All usage data, network metrics, and process statistics remain strictly on your device and are never shared or sent over the Internet.

5. Notifications & Reminders

K-Cleaner includes optional background notifications to remind you to review accumulated junk files and keep your device clean.

  • Daily Rate Limit: Notifications are strictly capped at a maximum of two (2) notifications per calendar day via our local limiter.
  • Quiet Hours: Notifications are automatically suppressed during quiet hours (between 10:00 PM and 7:30 AM local time).
  • Ad-Free Quick Boost: When you tap the Quick Boost action directly from an expanded notification, the background cleanup executes immediately without showing an advertisement.
  • User Control: You can enable or disable notifications at any time directly in K-Cleaner's Settings > Notifications or via Android System App Settings.

10. Data Retention, Deletion & User Controls

Because K-Cleaner does not store your files or personal records on external servers, you maintain total ownership and direct custody of your data at all times:

  • Local Storage & Preferences: App preferences (such as your chosen theme mode, language preference, notification toggle, and first-launch status) are stored locally in Android's private SharedPreferences on your device.
  • Permission Revocation: You can revoke any granted permission (Storage, Media, Usage Access, Notifications) at any time through Android Settings > Apps > K-Cleaner > Permissions.
  • Clearing Application Data: You can completely purge all local settings and cached records by navigating to Android Settings > Apps > K-Cleaner > Storage > Clear Data.
  • Application Uninstallation: Uninstalling K-Cleaner immediately and permanently erases all locally stored application preferences, internal temporary caches, and database files from your device.
  • Resetting Advertising ID: You can reset or delete your device's Google Advertising ID at any time via Android Settings > Google > Ads > Reset/Delete advertising ID.

13. Security Safeguards

We employ industry-standard Android security architectures to protect the integrity of the Application:

  • Local-First Design: By not operating an external cloud database of user files, the risk of remote server breaches or unauthorized third-party file leakage is eliminated.
  • Least-Privilege Configuration: Internal application components, custom broadcast receivers, and our FileProvider are configured with android:exported="false" to prevent unauthorized inter-process communication from other apps.
  • Operating System Sandboxing: Android's application sandbox isolates K-Cleaner's executable code and private data storage from other applications installed on your device.

While we implement robust safeguards, no electronic transmission or storage method is completely impenetrable. We encourage users to maintain up-to-date operating system security patches on their devices.
